# 💬 Sniz — Real-Time Chat Application

**Sniz** is a modern real-time chat application that enables seamless communication through **public chat rooms** and **private messaging**. Built with **React**, **TypeScript**, **Node.js**, and **Socket.IO**, it delivers fast, low-latency communication with a clean and responsive user interface.

Whether you're chatting with everyone in a room or having a one-on-one conversation, Sniz provides a smooth and engaging real-time messaging experience.

---

## ✨ Features

### ⚡ Real-Time Communication
- Instant message delivery powered by **Socket.IO**
- Low-latency bidirectional communication
- Live updates without page refreshes

### 🌍 Public Chat Rooms
- Join shared chat rooms instantly
- Automatically connect to the **General** room
- Participate in group conversations in real time

### 💬 Private Messaging
- Start direct conversations with connected users
- Secure one-to-one messaging experience
- Easily switch between public and private chats

### 🟢 Live User Presence
- View all currently connected users
- Real-time online/offline status updates
- Quickly initiate private conversations

### 🎨 Modern User Interface
- Clean and responsive design
- Fully optimized for desktop and mobile devices
- Dark-themed interface for a comfortable user experience
- Beautiful icons powered by **Lucide React**

### 🚀 Developer Friendly
- Built using modern technologies
- Fully typed with TypeScript
- Fast development workflow with Vite
- Modular and scalable project structure
